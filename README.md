# CSC584-Individual-Assignment-1

Personal Profile Web Application
1. Project Overview
The Personal Profile Web Application is a web-based application. The main purpose of this application is to allow users to submit, view and update their personal information through a simple and user-friendly interface. The application provides an organized way to manage personal profile information using HTML, CSS, Java Servlet and JavaServer Pages (JSP).

2. Application Features
The application consists of the following features:

a. Personal Profile Form
- Allows users to enter their personal information.
- Collects six fields: Full Name, Student ID, Programme, Email Address, Hobbies and Short Self-Introduction.
- Includes Submit and Reset buttons.
b. Dashboard
- Provides a central navigation page.
- Allows users to access My Profile and Edit Profile.
- Displays a brief description of the application.
c. My Profile
- Displays previously submitted personal information.
- Presents the information in an organized format.
- Provides navigation back to the dashboard.
d. Edit Profile
- Allows users to modify their existing personal information.
- Automatically displays previously submitted information in the form.
- Allows users to update their profile.

4. Technologies Used
The following technologies and tools were used to develop this application:

- HTML: Creating the personal profile form
- CSS: Designing and styling the web pages
- Java: Implementing application logic
- Java Servlet: Processing form submissions and profile updates
- JSP: Displaying profile information and application pages
- HTTP Session: Maintaining submitted profile information
  
5. How to Run the Application
   
1. Download or clone this repository.
2. Open NetBeans IDE.
3. Import or open the project.
4. Clean and Build the project.
5. Run the application.
